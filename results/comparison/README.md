# Comparison evidence

The current three-model comparison, including earlier and retuned HGB results,
is generated by [`report/analyze_results.py`](../../report/analyze_results.py).
Read the [four-page report](../../report/COMP90051_Final_Report.pdf) and the
[tables and figure](../../report/results/).

The files in this directory belong to the earlier detailed observation
reports. They are retained unchanged so their input hashes, numerical
conclusions, and analysis history remain inspectable. In particular,
`observations_main_summary.csv` contains LR and TabM, while
`hgb_reported_reference.json` records the earlier HGB summary.

| Artifact | Purpose |
| --- | --- |
| `output_data/observations_main_summary.csv` | Earlier LR/TabM summary |
| `output_data/observations_method_differences.csv` | Paired arm/control differences |
| `output_data/observations_input_manifest.json` | Hashes of the original observation inputs |
| `output_data/observations_pairing_validation.json` | Matching LR/TabM stress audits for 2,480 shared conditions |
| `reports/preprocessing_validation.json` | Recorded shared preparation checks |
| `reports/workflow_validation.json` | Recorded observation-generation checks |

The older shared evaluation notebook expects an exported, combined prediction
schema. The new HGB delivery has its own CSV/ZIP schema, so the report audit
reads it directly. A missing combined notebook export does not mean that the
new HGB predictions are missing. HGB uses a different stress seed stream from
LR/TabM; fold-level comparisons do not establish identical perturbation draws.
